# Argus v2 — token-efficient pipeline

v1 ran `claude-code-action` as an open-ended agent on every push, re-sending a
growing context each tool turn (≈100:1 input:output, ~$4.3k/30d). v2 replaces the
agent loop with a **deterministic pipeline** — the model never uses tools; scripts
gather context and post results. Target: ≥80% cost cut, same blocker/major recall.

## Pipeline (`src/main.py`)

```
debounce → gate → delta → context pack → budget → triage(Haiku) → review(Haiku|Sonnet) → merge → post → record
```

- **debounce** — on a push, wait `debounce_minutes` then check for a newer commit; superseded runs make **zero** model calls.
- **gate** (`gate.py`) — draft / bot / lockfile-only / oversized → no review (or summary-only), no LLM.
- **delta** (`delta.py`) — review only `last_reviewed_sha..HEAD`; trivial/empty deltas post a note with zero model calls.
- **context pack** (`context_pack.py`) — diff hunks + ±N HEAD context + bounded symbol signatures + **only path-matched rubrics**; cache-stable stable prefix; hard token budget with announced trims.
- **triage** (Haiku, 1 call) → `trivial` short-circuits; `risk` picks the review model.
- **review** — Haiku for low/medium, Sonnet only for high-risk (or `strict_globs`), scoped to `files_for_deep_review`.
- **post** (`post.py`) — review bound to `commit_id` (verdict + inline), one editable summary comment holding the hidden state marker + cost line.
- **record** — `argus-run.json` with token/cost breakdown (see `cost.md`).

**Unchanged:** verdict policy (`gate` + `verdict.allow_approve`), per-repo memory
isolation, fork-PR skipping, "a green check reviewed this commit", SHA pinning.

## Rollout (do not re-enable blind — spec §9)

1. **Credentials:** dedicated Anthropic workspace "argus" with a Console spend
   limit; per-org key `ARGUS_ANTHROPIC_API_KEY`. Remove personal keys from org secrets.
2. **Retire duplicates:** delete `claude-review-dev.yml` / `claude-review-main.yml`
   in every consuming repo (see §5). Argus is the single PR reviewer.
3. **Shadow** in the lowest-volume repo (`xspan-agent-admin`) — artifacts only.
4. **Canary** post-mode in `xspan-agent-admin` + `xspan-llm` for a week; daily cost check.
5. Roll out to the rest; then port to pdxlab (Foundry provider via a `provider:` switch — not yet built).
